# Reduce the shared time series contract and add a bounded stepwise family

Chrono currently treats all time series implementations as point-presence structures through `ITimeSeries<T>`, but the new memory-reduced series has different semantics: it has an explicit logical range, dense logical reads within that range, canonical change-point compression, contiguous-only range expansion, and no hole-producing removes. We will reduce the shared contract to true commonalities, introduce `ISparseTimeSeries<T>` for the existing point-presence implementations, introduce `IBoundedStepwiseTimeSeries<T>` for the new bounded stepwise family, keep segment writes and single-slot writes with inclusive-start/exclusive-end range semantics, and implement the new concrete type as `StepwiseTimeSeries<T>` because forcing those semantics into the existing abstraction would make `Count`, enumeration, and mutation behavior misleading.
